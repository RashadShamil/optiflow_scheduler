CORRECTED OPTIFLOW CLEANUP V3

PRESERVED / REBUILT REAL FEATURES
- Manager creates a print job + complete task DAG before scheduling.
- Each task explicitly requires MACHINE, HUMAN, or MACHINE + HUMAN together.
- Capabilities choose compatible resources, processing rate, setup time and cost.
- Manager explicitly clicks Optimize; other DRAFT jobs are not auto-scheduled.
- Existing not-started/unlocked scheduled work may move for new urgent jobs.
- Priority and deadline affect the CP-SAT objective.
- Shop hours are configurable; work spills into later working days, never overnight.
- Approved external machine bookings block the optimizer.
- Editable Gantt shows both machines and humans; tasks requiring both appear twice.
- Gantt drag/drop can change time and compatible resource and creates a manual lock.
- Manager can unlock a task so a later optimizer run may rearrange it.
- Internal human task workflow: SCHEDULED -> OFFERED -> ACCEPTED -> IN_PROGRESS -> COMPLETED.
- External work marketplace contains individual HUMAN-only tasks only after manager approval.
- External machine booking is request -> manager APPROVED/REJECTED; no online payment.
- QR machine scanning is retained.
- Role-based app: MANAGER / WORKER / EXTERNAL.
- Desktop and mobile share the same FastAPI API and Supabase data.
